# Snag.Ai — Downloads

Public download page and privacy policy for the Snag.Ai Android app.
The app's source code is maintained in a separate private repository.

- Download page: https://archdeyab-eng.github.io/snagai-downloads/
- Direct APK link (always the latest release, stable filename): https://github.com/archdeyab-eng/snagai-downloads/releases/latest/download/snagai-latest.apk
- Privacy policy: https://archdeyab-eng.github.io/snagai-downloads/privacy-policy.html

To publish a new version: upload the new APK as a release asset named exactly
`snagai-latest.apk` (e.g. `gh release upload <tag> snagai-latest.apk --clobber`)
so the download page's link never needs to change.
